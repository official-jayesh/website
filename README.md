# 🌌 Jayesh Singh — Digital Space

> A small corner of the internet belonging to **Jayesh Singh**.

This repository contains the source code for my personal GitHub Pages website.

The site is intentionally simple for now — a futuristic, space-inspired landing page that serves as a placeholder while the rest of the space is being built.

### ✨ What you'll find

- 🌌 Animated space-inspired background
- ⭐ Subtle stars and atmospheric effects
- 💻 Minimal futuristic interface
- 🐶 An interactive little puppy
- 💬 A few hidden surprises when you interact with it
- 📱 Responsive design for desktop and mobile
- 🚀 Built with plain HTML, CSS and JavaScript

### 🐾 The Puppy

Yes, the puppy is intentional.

Click it and it'll go for a little run across the page before proudly returning home.

Because every unfinished website deserves a puppy.

### 🛠️ Built With
